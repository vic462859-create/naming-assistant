# naming-assistant · 中文起名助手

豆包工作区技能：**双轨制中文起名 / 点评 / 补字（表字）系统**。

## 定位

- **审美轨**（姓氏型格学：两维四型 + 三原则）定名字气质方向
- **命理轨**（八字喜用神 + 五行补益）定五行补益方向
- **传统文化维度**（典籍取字 / 字辈 / 名·字·号 / 避讳 / 时令地理）定文化之根
- **独一性机制**（差异化锚点 × 字库分层 × 结构多样化 × 组名设计）防同构撞名
- 六层校验（三条金线 / 三原则 / 音韵 / 命理复查 / 传统校验 / 独一性）后输出方案清单

## 覆盖口径（诚实声明）

- 内置姓氏档案：**约 115 常见姓**（`surname-roster.md`）+ **约 50 疑难姓**（`surname-special.md`：多音/复姓/生僻）≈ **165 姓直查**
- 其余任意姓：按 `surname-taxonomy.md` **标准化判定卡（三步法）**现场判定
- 方言：按 `dialect-taboo.md` 三步验读（问方言→三地验读→三类检测）

## 使用

触发"起名 / 取名 / 改名 / 点评名字 / 分析姓氏搭配 / 补字"即启用。三种场景：起名（完整清单）、点评（逐条打分）、补字（六种咬合关系出候选字）。
