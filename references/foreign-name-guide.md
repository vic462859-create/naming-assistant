# 外籍起名指南（Foreign-Name Guide）

服务对象：**外国人、跨国婚姻子女、海外华人后代起中文名**。给外籍人士起中文名早已超越简单音译，是一门融合语言学、文化心理与社交智慧的学问——核心是**"音、义、形"三者的巧妙结合**。

**定位**：本分支起点为**无中国姓氏**——技能主线"姓氏中心主义"（姓是根，名是枝叶）对外籍场景不适用。因此走独立流程：**先选姓、再按路径取名**；选好姓/名之后，主线资产（字库、音韵校验、三条金线、独一性、命理轨）**全部复用**。

## 一、姓氏策略（先选一个地道中文姓氏）

选姓是"像中国人"的第一步，强烈建议从《百家姓》中挑常见姓——能有效避免名字听起来像地名或物品。

| 策略 | 做法 | 示例 |
|---|---|---|
| **谐音选姓**（最常用） | 按原名发音选音近汉姓 | Johnson→庄/乔/钟；Harford→韩；Kubin→顾 |
| **意译选姓** | 按原名含义译成汉姓 | Goldkorn（金玉米）→金 |
| **文化选姓** | 从《百家姓》挑常见姓，与原名无关 | 王/李/张/刘/陈/杨…… |
| **无姓两字名** | 直接名两字（少数场景） | — |

**要点**：优先常见大姓（王李张刘陈杨黄赵等），避免"冷僻姓+生僻名"叠加；姓选定后进入主线配字（`character-vault.md`）。

## 二、取名四路径

### 1. 改良音译法（最常用、门槛最低）
依据原名发音，挑**发音相近且寓意美好**的汉字。关键在于"改良"——主动避开负面谐音。
- **基本音译**：直接将姓名音译——David Baker → 白大卫
- **谐音雅化**：音近基础上选含义优雅的字——汉学家顾彬（Wolfgang Kubin）："彬"既谐音，又含"文质彬彬"
- **结合公司/情境**：结合所在公司、城市、场景取字——澳大利亚高管 Harold 结合公司名"威尔顿" → 魏华德
- **避开谐音陷阱**（关键）：安灯泡（Adam Powell）、安卓（Andrew）、王姐夫（Jeff）——在中国人听来尴尬的名字，必须主动排查

### 2. 意译/原意转化法（保留原名灵魂）
挖掘外文原名本身含义，再用中文表达，保留原名承载的祝福与文化背景——Jeremy Goldkorn → 金玉米（Goldkorn 直译）。

### 3. 音义结合法（最受推崇的理想模式，"信达雅"）
通常**"姓"用音译贴近原姓，"名"用意译或谐音赋予美好含义**：
- 经典：费正清（John King Fairbank）——姓"费"音近 Fairbank，名"正清"寓意正直清廉
- 现代：韩懋宇（Michael Harford）——"韩"谐音 Harford，"懋宇"寓意勤奋与宇宙

### 4. 文化借用与自主创作
- **借用文化意象**：从古诗文、历史、自然中汲取——埃及留学生因爱写诗被老师取名"苏轼"；"兰天"寓意心胸如天空般广阔
- **人物特征法**：结合性格或外貌特征——高大英俊的 Ghagen → 高俊
- **主题自主创作**：设定主题自行创作（适合课堂/教学场景）

## 三、铁律与避坑

1. **长度 2-3 字**：标准中文名是"单姓+单名/双名"，总长两到三个字，简洁正式。
2. **谐音三重核查**：字面可读、连读无尴尬、时代感不过时——"史珍香""申景冰""翠花"单看字面尚可，读音或时代感会带来尴尬。起名后务必请母语者读几遍（对应 `dialect-taboo.md` 三步验读）。
3. **避免名人/伟人名字**：直接使用"曹操""李白""孙子"类在中国文化中被视为过于自负或不恰当——与西方沿用家族先辈名字的习惯不同。
4. **母语者把关**：中西文化差异巨大，最稳妥是请中文母语者/老师帮忙把关，确保发音、含义、文化联想都得体。
5. **名从主人**：汉名须经本人认可；涉及护照/正式场合时说明汉名与护照名的一致性。

## 五、案例（公开素材整理）

| 中文名 | 原名 | 路径 | 说明 |
|---|---|---|---|
| 白大卫 | David Baker | 改良音译 | 姓+名整体音译 |
| 顾彬 | Wolfgang Kubin | 谐音雅化 | 彬=音近+文质彬彬 |
| 魏华德 | Harold | 情境结合 | 结合公司"威尔顿" |
| 费正清 | John King Fairbank | 音义结合 | 费=音译姓；正清=正直清廉 |
| 金玉米 | Jeremy Goldkorn | 意译 | Goldkorn 直译 |
| 韩懋宇 | Michael Harford | 音义结合 | 韩=谐音姓；懋宇=勤奋宇宙 |
| 高俊 | Ghagen | 人物特征 | 高大英俊 |
| 兰天 | — | 文化意象 | 心胸如天空 |

**负例（谐音陷阱）**：安灯泡（Adam Powell）、安卓（Andrew）、王姐夫（Jeff）、史珍香、申景冰、翠花——字面尚可或音译贴近，但连读/时代感翻车。
