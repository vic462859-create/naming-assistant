# 命理轨：八字与喜用神参考（核心维度之一）

本文件是技能**命理轨**的操作框架，与 `surname-taxonomy.md` 的**审美轨**并列。起名走双轨：审美轨定名字的气质方向，命理轨定五行的补益方向，两条轨联合约束选字。
命理轨属**传统民俗体系**（源自唐·李虚中、完善于宋·徐子平），技能负责任地完整呈现其通行操作框架，但明确：它可证伪性弱、不承诺吉凶。精确排盘以专业命理工具/命理师为准，本文件提供的是可执行的简化框架与字库。

## 一、八字排盘基础

- **八字**：出生年、月、日、时各配一个天干+地支，共八个字。
- **十天干**：甲(木) 乙(木) 丙(火) 丁(火) 戊(土) 己(土) 庚(金) 辛(金) 壬(水) 癸(水)。
- **十二地支**：子(水) 丑(土) 寅(木) 卯(木) 辰(土) 巳(火) 午(火) 未(土) 申(金) 酉(金) 戌(土) 亥(水)。
- **五行属性速查**：天干地支五行即上两行括注。八字五行分布 = 把八字的五行属性逐项列出（如：庚申=金金、丙午=火火、戊辰=土土、甲寅=木木 → 金2火2土2木2水0）。
- **年份干支快速法**：天干 = (年份尾数对应：4甲5乙6丙7丁8戊9己0庚1辛2壬3癸)；地支 = (年份%12：0申1酉2戌3亥4子5丑6寅7卯8辰9巳10午11未)。例：2026年 → 尾数6=丙、2026%12=10=午 → 丙午年（马年）。
- **月柱/时柱**：精确排盘需节气与时辰表，AI 场景建议：用户提供完整出生信息时给出排盘方法并标注"以专业工具校准"，不自行硬排易错；至少年柱、日主（出生日天干）是起名最常用的依据。

## 二、五行生克与流通

- **相生**：木→火→土→金→水→木（生者泄气，被生者受益）。
- **相克**：木→土→水→火→金→木（克者耗力，被克者受损）。
- **流通**：八字各五行有生有克、循环不绝为"流通好"；某五行孤立无生扶或被克无救为"流通差"。
- **命名视角**：不追求五行全备，追求"日主有根、用神有力"；名字补的是日主与用神的需要，不是简单数个数。

## 三、日主强弱与喜用神判定

1. **定日主**：日柱的天干（出生日的天干）即日主，代表命主本人。
2. **判强弱（简化法）**：
   - 日主在八字中出现的次数（本气+得令加分）——同五行多、又得月令生扶 → 偏强。
   - 日主被克泄耗多、生扶少 → 偏弱。
   - 强弱是相对判断，AI 执行时给出倾向即可，精确以命理师为准。
3. **定用神**：对日主最有用的五行。
   - 日主弱 → 用神 = 生扶日主的五行（印=生我的、比劫=同我的）。
   - 日主强 → 用神 = 克制/泄耗日主的五行（官杀=克我的、食伤=我生的、财=我克的）。
4. **定喜神**：辅助用神的五行（生用神的五行）。
5. **补益方向**：用神/喜神所在五行即名字要补的五行；若某五行明显缺失且为用神，重点补；若缺失但为忌神，不补甚至避用。

## 四、补益方法论

- **补法**：通过名字用字的五行属性补入用神/喜神五行（见第五节字库）。
- **原则**：补"有用"不补"凑数"。五行缺≠必须补，只有缺的正好是用神/喜神才补；忌神五行不因缺而补。
- **配合**：姓的五行也在盘内，名与姓的五行构成生克关系时，以"名助姓、姓不伤用神"为优（如姓属金、用神属水 → 金生水，顺势；姓属火、用神属水 → 火克水，须慎重或换补法）。
- **表述**：所有结论写成"补益参考"——如"日主偏弱，宜补金水，名中可着金水字"。

## 六、命理×审美的联合使用

1. **双轨约束**：审美轨先定型格与配字方向（`surname-taxonomy.md`），命理轨定补益五行（本节）。候选字 = 两个方向的交集。
2. **冲突裁决**：某字命理补益但违背该姓型格 → 以型格与三原则为准，换同五行的其他字；某字型格完美但五行相克 → 调整补法（双字名可用另一字补，或在同五行字库中重选）。
3. **三美校验**（与命理无关的审美底线，仍须过）：意韵美（有画面）、音律美（声调起伏）、形态结构美（笔画独立书写流畅）。
4. **卦理校验**（可选深水区）：传统做法最后以六十四卦卦理校验吉名，AI 场景标注"深水区，需专业工具，不作默认步骤"。

## 七、客观性与合规边界

1. **定位**：命理轨是民俗参考框架，完整呈现但不包装成科学；不承诺吉凶祸福、不宣称"补了某五行就能如何"。
2. **输入门槛**：用户提供出生年月日时（至少年月日）才启用命理轨；未提供则单轨输出（审美轨），并说明"未提供出生信息，命理轨已跳过"。
3. **场景分级**：一对一客户沟通可完整展开命理轨；产出用于公开传播（公众号/抖音/视频）时，按平台规则处理命理表述——通常保留"补益参考"口吻、不出现"命理/八字/算命"等敏感词堆叠，必要时以"传统字源与音韵"替代展开。
4. **排盘校准**：年柱可手算（见第一节），月柱/日柱/时柱精确值建议以专业排盘工具校准，技能给出方向性结论即可，不假装精确。
