# 方言与口语谐音雷区（Dialect & Vernacular Taboo）

普通话校验之外的"**落地校验**"：名字最终要在家族方言与拟居地口语里使用——普通话没毛病的名字，方言可能翻车。本文件是方言层校验的操作框架。

## 目录
1. 为什么需要这一层
2. 验读流程（三步）
3. 已知雷区表（高置信，范围标注）
4. 多音姓与方言读音（衔接）
5. 客观边界

## 一、为什么需要这一层

- **同一字多方言异读**：普通话无碍、某方言谐音不雅（粤语区"茂"组"茂利"=呆子俚语）。
- **网络语境污染**：字被网络语言赋予贬义，全国通用（如"翔"）。
- **文化烙印**：重男轻女式结构（招娣/来娣）、性别化歧义。

## 二、验读流程（三步）

1. **问方言**：出生地/家族主要方言/拟居地——深圳广州→粤语；上海/苏南→吴语；福建→闽南语；客区→客家话；川渝→西南官话。
2. **三地验读**：普通话 + 家族方言 + 拟居地方言，把候选名各连读一遍。
3. **三类检测**：
   - 方言不雅谐音：连读撞脏话、俚语贬义词。
   - 网络污染：字是否被网络语境污化（翔/菊/基类）。
   - 性别化/烙印：重男轻女式结构、男化/女化歧义。

## 三、已知雷区表（高置信，范围标注）

| 字/组合 | 问题语境 | 处理 |
|---|---|---|
| 翔 | 网络贬义（全国通用，"翔"网络指秽物） | 避免 |
| 茂 | 粤语"茂利"（呆子俚语） | 粤语区慎用 |
| 娣 | 粤语同"弟"（男化）；重男轻女烙印（招娣/来娣） | 避免 |
| 基 | 粤语"基佬"（男同贬称）、网络"基" | 避免 |
| 爽 | 口语歧义、偏俗（"很爽"歧义） | 名中慎用 |
| 浪 | 各地方言多负面（轻浮义） | 硬排除 |
| 淫 / 贱 | 各地方言均负面 | 硬排除 |
| 招（招娣式） | 重男轻女文化烙印 | 避免 |
| 阿X 单字名 | 吴语/粤语"阿"为称呼前缀，单字名易被读成"阿X" | 注意连读提示 |

**说明**：方言是动态的，同一字在不同村县口径可能不同——本表是**提示**不是**禁令**；最终以用户实际方言区验读为准（校验时主动问）。

## 五、客观边界

- 方言雷区无法穷尽，核心是"**验读流程**"——每名必问方言、必验读。
- 不制造焦虑：方言问题只作提示与替换，不作一票否决；用户明确偏好某字时保留并标注风险。
