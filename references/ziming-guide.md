# 表字指南（字·名互为表里）

本文件是"补字"的完整操作指南。定位：**名出生所取、字成年所取（《礼记》"幼名，冠字"），字的功能是补充解释名**（《白虎通》"闻名即知其字，闻字即知其名"）。"已有名字再补字"不是起第二个名字，而是给名配一个文化"注脚"——名不动、字新增，是最传统、风险最低的文化增值操作。

## 一、补字定位

- **名**：出生所取、户口本、社交资产——不可轻改。
- **字**：成年所取、文化身份、与名互为表里——可补。
- **补字 = 名不动 + 字新增**：正式场合、书画落款、文化自称可用。
- **价值**：把"一个称呼"升级成"一套自洽的文化系统"；区别于普通起名号的差异化增值项。

## 二、六种咬合关系

| 关系 | 逻辑 | 古籍范本 |
|---|---|---|
| 同义相释 | 字解释名的含义 | 亮·孔明（亮=明） |
| 反义相成 | 字与名反义互补 | 熹·元晦（光明×昏暗）、愈·退之（进×不妄进） |
| 联想引申 | 字延伸名的意象 | 飞·鹏举 |
| 典源共出 | 名与字出自同一经典语境，互相咬合 | 守仁·伯安（《论语》"仁者安仁"）、梦得·禹锡（《尚书》"禹锡玄圭"）、怀瑾·握瑜（《楚辞》同句） |
| 对举并列 | 名与字同物类/意象，并列互文 | 丘·仲尼（皆山）、云·子龙（《周易》"云从龙"）、望舒·羲和（日月御对举） |
| 动静互补 | 名显外（责任/格局）、字修内（修身/性情） | 国藩·涤生（外藩内涤）、静好·行健（一静一动） |

**变体**：拆字同头（安·安石——字含名之字头，同源展开），可作第 7 种灵活处理。

**判定补充（重要，防误判）**：互补类关系**不可只拘泥"同语义轴"**（愈×退之式：进/退同一轴）。传统真实存在的还有**气质互补**：刚×柔、燥×润、火×水——名显外、字修内即可成立：
- 国藩·涤生：国之藩篱（刚守）×涤洗重生（润洗）——刚守配润洗，正宗动静互补。
- 熹·元晦：光明×昏暗——异范畴反义，正宗反义相成。
- 火性/刚烈之名配水润/柔润之字，属正宗互补路径；判定时不得以"不同范畴"一律否定，先看是否构成"名显外、字修内"的气质互补。

## 三、字的结构惯例

- **先秦两汉**：单字名+排行/尊称（伯夷、叔齐、仲尼、子舆、子瞻）——"伯仲叔季"表排行、"子"表尊称。
- **唐宋后**：双字成主流（退之、乐天、梦得、鹏举）。
- **今人适配**：不须带排行（家族排行语境已失）；"子"字头、"之"字尾可作结构点缀；单双字皆可，双字更古典、单字更凝练。

## 四、补字流程（5步）

1. **拆解名**：判定名的字义、结构（动宾/偏正/并列）、所属型格方向（过一遍 `surname-taxonomy.md`）。
2. **定关系**：从六种关系中选方向——优先**典源共出**（同出经典一句最"天衣无缝"）；其次对举并列/动静互补；同义、反义、引申为通用兜底。
3. **生成候选字**：围绕名之意象/出处选字（2-4 个候选，用 `character-vault.md` 与典籍字）。
4. **校验**：四条（见第五节）。
5. **输出**：候选字 + 关系说明 + 典故出处（可查证，不虚构）。

## 五、四条校验

1. **六关系必居其一**——字与名互为表里；无关硬拼=废（等于两个不相干的名字）。
2. **过音韵**——与姓连读、与名连读都要顺（声调起伏、谐音避雷，见 `character-vault.md` 第六节）。**名与字之间的平仄可收放互补**（名硬收、字缓收，如名仄仄、字平平），属辅助加分维度，不作硬性否定。
3. **贴合型格**——字也顺着姓氏脾气走（配字方向同起名规则）。
4. **避讳 + 独一性**（补字同样过独一性，防止"字"也批量撞名）——
   - **尊长避讳**：不与长辈重字同音。
   - **名字不重**：字不与名重复用字、结构拉开。
   - **组内不重**：多子女补字，字与字之间不重复用字、不共用同一结构（呼应靠意象同源，不靠字面）。
   - **经典拉开**：今人补字避免直接复用历史名人之字（孔明/子昂/鹏举式）——历史名人之字作范本、不作字面照搬；撞则标注"与历史名人字重合，建议换向"。
   - **模板预警**：识别补字高频俗配（"子X""X之"类被用滥的结构），降级处理；字撞车时对照 `uniqueness-guide.md` 撞车替换表同意象换字，并在"独一性"栏注明替换原因。

## 七、双胞胎/兄弟姐妹同源配字

多子女场景：**名各自独立（互不干扰），字可同源呼应**——名是各自起好的，字补上"一套体系"的家族感：

- **同出经典一句**：名上句、字下句（怀瑾×握瑜式拆给两人：一人字怀瑾、一人字握瑜；或两人字同出对句）。
- **同取对举意象**：日月、云龙、凤麟、琴瑟（一人配其一）。
- **呼应优先级**：典源同句 ＞ 意象对举 ＞ 同韵收尾——呼应不以牺牲独立为代价。

## 八、客观边界

- 名·字体系是传统礼制文化（冠礼/笄礼），今人补字是**文化再诠释**，不是恢复礼制。
- 字不改变名的任何法律/社交属性，纯文化附加；用户可不用、可只用其中一个候选。
- 关系与出处可查证、不虚构典故；无典源时写"常用字，训诂平实"，不硬编出处。
