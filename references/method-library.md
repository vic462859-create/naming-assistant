# 起名方法对照库（公开方法论整理）

本文件整理公开起名内容（口播视频/文献）中流传的完整方法论，作为技能的方法对照库与灵感来源。所有条目从公开内容系统还原，区分学术表述层与大众传播层。**使用前必读第五节批判性备注**——本库是借鉴对象，不是免检真理；已吸收进技能的条目以技能自身语言体系为准。

## 一、认知底座

1. **反内耗**：没有完美名字，别追求人人说好；找"锦上添花"的好名字。反"克父母/必须改"式的焦虑营销，建立"有温度、不PUA"的起名师人设。
2. **时间观**：名字要对抗短暂感觉与流行（"流行像风"），要经典耐看、无年代感体质——不迎合任何短暂潮流，才能抵御所有潮流更迭。
3. **人如其名（名要向人）**：名副其实——不是名字决定命运，而是"人的行为成就名字的语义"。正面（于谦/苏轼/陶行知/朱自清）与反面（胡惟庸）双向例证。
4. **减法美学**：越用力越廉价，越从容越耐品；好名字是做减法（钱钟书/杨绛/沈从文/朱自清），塞得越满越像密码。

## 二、姓氏中心主义（公理）

**公理**：姓是根，名是枝叶；起名从姓氏出发，不堆砌寓意。"顶级的名字姓与名浑然天成，像本来就在一起。"
- **推论A 姓氏脾气论**：稳性姓（孙张李刘谌）贴端正重心字、怕硬凹意境；佛性姓（江林石沈孟顾钟）围绕姓义构画面、怕中性臣字。详见 `surname-taxonomy.md`。
- **推论B 大姓小姓分流**：大姓（高频姓）走"宽度/破局"——取端庄稳重、重结构气度，或熟字新组合跳出同质化；小姓（低频姓）走"深度/雅致"——顺势延伸姓氏意象、守拙平实，越平实越衬出姓的独特。多版本口诀统一：**大姓求新≠生僻，是熟字新组合（陈都灵/张劲夫/张译）；小姓守拙≠平庸，是平字衬贵（清子/依纯/诗曼）**。
- **推论C 冷门姓观物取象**：顺着姓氏本意就近找意象，不硬凑生僻字（文→文剑秋、陆→陆清溪、池→池映月）。

## 三、生成方法库

1. **姓氏脾气两分**（稳性/佛性，见 taxonomy）——认知起点。
2. **大姓求新·小姓守拙**：十六字诀"大姓求新破局而出，小姓守拙以平见奇"。
3. **大姓取宽度·小姓取深度**：十六字诀"大姓拓宽舒展格局，小姓挖深强化特质"；大姓可不必名姓结合（周迅/孙俪/胡歌），小姓必强化唯一性（江疏影/白敬亭/梅兰芳）。
4. **大开大合·气势**：独体字（山月川日中天）+ 灵动字（越/跃/拓/骋）；灵动字配感性字平衡（金月/行越），忌配名词（越山/越石）。
5. **留白三句箴言**："用字求简不求繁，寓意要藏不要露，整体要自然切忌刻意"——名字如中国画，妙在留白（林风眠/江疏影）；忌堆砌光明俊美字（浩辰/俊熙/子睿=太满太漏）。
6. **名姓交融·出场设置**：姓是场景名是动作（林风眠=风吹林间眠于树下）；名姓一体案例（江万里/月凌霄/云见月/路观海）。
7. **动词入名（活字）**：动词让名字"从照片变成电影"——执（握持坚守）/临（到来俯瞰）/遇（邂逅相逢）：如季青林、吴宇安。名字本身就是一个生动的故事。
8. **双核心思路**：一姓义延伸浑然天成（顺着姓的感觉找呼应字）；二动静相宜平衡有巧（偏静+偏动组合：马一川动中有静、陶春意静中运动）。
9. **熟见少用字（书卷气两步）**：①选日常熟脸但入名少见的字（允直出《尚书》、既明出《诗经》——不冷僻却有根）；②避开被网络审美用腻的字（子宣/木熙/宸诺/宁宥类）。
10. **跨层字（大姓配平字）**：单看平的字放高频姓后拉开层次（刘先宁的宁/张万森的万/徐开骋的开）；直接从历史名人找——王维的维/杜牧的牧/苏轼的轼/陆游的游，历久弥新。
11. **气场字**：能力主线字（真/成/源）立气场（竺可桢/梁思成/周培源）；避"轩/潮/烟/锦/灿"类——车马来来去去、潮水退得快、烟风一吹就晃、锦灿热闹是散的。
12. **力量感·不幼态**：去甜腻、脱稚气、立风骨、建格局（十二字诀）；忌网红小说名/文弱小书生感（张慕白/何淑毅/林若莲/楚晚风类）。
13. **成长性·大人感**：名字要能长大——把泽的空间撑开（泽川/泽月而非泽宇/泽轩）、宁给环境（宁川/宁月而非宁轩）；测试法：想象印在名片上、50岁坐会议室、正式场合被介绍"某先生/某女士"。
14. **女孩名不娇柔**：用名词动词虚词、就是不用形容词；无娇婉柔、无花无烟（林徽因/孟晚舟/秋瑾/叶嘉莹）；忌棉花糖名（雨桐/心怡/诗宁）。
15. **名副其实**：十六字诀"字义要纯，组词要多，立意中立，名要向人"；慎用字面漂亮底子单薄的字（沐=洗头浸湿，湿漉漉跟一辈子）。
16. **止贪·正念**：戒贪不追功利、返璞归真；正面不逐虚华、起心向人；立诚不违本心、恪守真诚；忌攀龙附凤字（弘正/彭远/琛耀庭）与金银玉器字（琛瑶锦）。
17. **反装·落地见真**：好名字"懂的人更肯定，不懂的人不排斥"（梅兰芳/关山月/林风眠）；选国民普及的字，凡要人多想一秒就是不好懂；忌堆古风词藻（叶清雪/白洛莹/顾清弦/谢云岫类）与生僻字（避生就熟、趋吉避讳、删繁就简）。

## 四、校验体系（4层）

1. **三条金线（大众传播版底线）**：音顺（读音流畅声韵和谐）/意实（寓意扎实有根骨实景不虚）/形美（结构匀称忌生僻）。见 `character-vault.md` 第八节。
2. **四维版**：寓意深远、读音悦耳、字形优美、意境隽永（"四方面多下功夫"）。
3. **三美（学术表述版）**：意韵美/音律美/形态结构美。见 `wuxing-reference.md` 第六节。
4. **字间咬合**："打断骨头连着筋"——名内两字要有语法关系（王安石=安石：状态+本体，拆不开；胡惟庸=惟庸：思虑+恒常）；尾字走向与姓氏语境共同定势。

## 五、批判性备注（用前必读）

1. **焦虑置换**：一边"反内耗"（没有完美名字别纠结），一边大量制造"过时/长大/气场"焦虑（子轩书记/慕辰部长/50岁尴尬）——用"时代感焦虑"替代"吉凶焦虑"，本质仍是焦虑营销，只是更高级。借鉴话术时要看清这一点。
2. **案例同构（模板化生产）**：公开内容中的结尾案例几乎全是同一结构"姓+动宾画面"（城见山/周听雨/沈知秋/江见岳……），署名感强但同质化明显——这是可复制的SOP，也意味着"自创案例"是批量化生成的。
3. **幸存者偏差**："人如其名"只用名字与人生恰好呼应的名人（于谦/苏轼/陶行知）证明，历史上名字好而人生惨淡、名字差而功业卓著者大量存在未提及；靠"名要向人"（人的行为成就名字）绕开宿命论，逻辑自洽但案例选取有偏。
4. **可证伪性弱**：审美判断与"经典耐看"无法严格验证；"过时/不过时"是事后判断，10年前的浩宇心怡当年也被认为寓意美好。
5. **同一主题多版本**：大姓小姓出现4个版本口诀（求新守拙/宽度深度/端庄雅致/越普通越高级），口径有重叠与微矛盾，使用时取"统一口径"（见第二节推论B），不逐条照搬。
6. **转写噪声**：公开文字稿中若干案例疑似转写误差（周之一/林建路/王为月/匕首拙/寒激情等），引用前需人工核对原文。
