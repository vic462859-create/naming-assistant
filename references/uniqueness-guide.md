# 独一性改造手册（Uniqueness Guide）

起名最大的隐性风险是**重名率失控**：同一套型格判定+同一批字库，会让所有同姓的人得出同构的名字——"用这套东西得出一样的名字"是系统级失败。本文件建立四道防线，把"独一性"变成可执行的生成与校验规则。

## 目录
1. 问题诊断：重名率的三重来源
2. 防线① 差异化因子（独一性的源头）
3. 防线② 字库分层（撞车率硬约束）

5. 防线④ 独一性校验（输出前把关）
6. 客观边界：独一性是概率优化
7. 组名设计（双胞胎/兄弟姐妹）

## 一、问题诊断：重名率的三重来源

1. **字库中心化**：AI 总是从型格字表的"中心区"取字（纯稳性→立守正承思，佛性→山川云澜），同型格的人踩同一批字。
2. **模板同构**：签名结构固定（姓+动宾画面/端正重心式），结构没得选，骨架全同。
3. **输入太薄**：只有姓+出生时间+风格偏好，没有"这个人是谁"的锚点；名字无锚，只能从公共字库中心抽样。

**结论**：独一性不可能来自字库本身，只能来自**具体的人**（出生场景、家庭寄托、地域谱系）。没有个性化输入时，AI 必须显式构造差异化锚点，而不是从字库中心抽样。

## 二、防线① 差异化因子（独一性的源头）

**定义**：每个候选名必须绑定 2-3 个差异化因子，名字 = 型格方向（对路） × 差异化因子（独有）。

**可采集的差异化因子（Step1 输入，用户提供优先）**：
- **出生场景**：时节/节气/时刻/天气（立秋、惊蛰、子时、雪夜、雨晨）——最常用。
- **父母寄语**：期待的一句话/关键词（踏实、开阔、温柔、坚韧）——最强的差异输入，直接决定寓意方向。
- **地域谱系**：籍贯山水、祖籍地标、出生地（生于钱塘→潮、生于泰山→岳）。
- **家族信息**：字辈排行、父母/兄姐名字（避重+呼应）。
- **出生意象**：出生当天的时令物候（秋桂、夏荷、冬雪、春山）。

**场景驱动法（无输入时的强制路径）**：用户未提供差异化因子时，AI 必须为**每个候选名虚构一个差异化场景**再取字——从"出生时节/节气/常见地域/父母普遍心境"中随机组合，如：立秋出生+盼孩子踏实 → 稔秋；钱塘江边出生 → 听潮；惊蛰出生+望其开阔 → 蛰川。
**规则**：禁止无锚点直接从字库中心取字。每个候选名的差异化因子写入输出"独一性"栏。

**锚点组合模板（反直接映射，至少组合2个因子）**：

| 组合方式 | 示例 |
|---|---|
| 时节 × 地域 | 惊蛰×钱塘 → 蛰川／听潮 |
| 时节 × 父母寄语 | 立秋×盼踏实 → 稔秋／穰丰 |
| 地域 × 家族字辈 | 钱塘×字辈"文" → 文澜／文江 |
| 出生意象 × 寄语 | 雪夜×盼坚韧 → 寒松／岁柏 |
| 双胞胎同源 | 同一锚点拆两意象：秋山 → 岳（山）+ 枫（秋） |

单一因子（只"惊蛰"）不得直接取字——必须加第二个因子（地域/寄语/家族）后才进入选字；同一锚点组合应能自然导出多个候选路径（惊蛰×钱塘→蛰川/听潮/澜生……），候选间路径拉开，禁止锚点→单字的固定映射。

## 三、防线② 字库分层（撞车率硬约束）

每类配字按**使用频率分三层**（`character-vault.md` 各节同步标注）：

- **中心层**（熟面孔、撞车高危）：立/正/承/思/川/山/云/澜类。保底可用，但**限用**。
- **次常层**（书卷气未滥）：翀/邈/遒/澹/骞/堇/荻/汀/岫/砚类——认得、少见、可校验。**主力层**。
- **冷门雅字层**（高风险高收益）：生僻边缘字。只作点缀，须过音韵与书写校验。

**硬规则**：
1. 每个候选名**至少一个字来自次常层或冷门层**（或来自差异化因子）——全中心层组合直接降级。
2. 整组 5-10 个候选名中，**全中心层组合最多 1 个**（作保底示范，不占主推位）。
3. 同一批候选名之间，**同一个字最多出现在 2 个候选**（组内去重用字）。

## 四、防线③ 结构多样化（打破模板同构）

每型格至少 4 条配字路径，**禁止只走签名结构**：

| 型格 | 路径1 | 路径2 | 路径3 | 路径4 |
|---|---|---|---|---|
| 纯稳性 | 端正重心（立言/守正） | 虚词+实景（之洞/若昀） | 典籍典源（允执/既明） | 反义对冲（陈曦/萧红） |
| 动词型 | 雅物宾语（望舒/知章） | 专名宾语（灵运/耐庵） | 场景化宾语（来自差异化因子） | 单字硬宾语（牧/拓） |
| 重器定势 | 重正古大（震岳/阳明） | 典源配重（出自典籍） | 动宾破势（听澜/望川） | 单字大器（衡/磐） |
| 佛性画面 | 姓义生长（江疏影式） | 动感行旅（沈从文式） | 风月静物（柳如是式） | 时令地理（稔秋式） |

**硬规则**：5-10 个候选名中，**同结构最多 2 个，至少覆盖 3 种结构**。宁可牺牲个别字面最优，也要保证结构多样性。

## 五、防线④ 独一性校验（输出前把关）

在 Step6 校验链末端加一条，每个候选名必查：

1. **撞车预警**：对照"型格高频组合表"（见 `character-vault.md` 第八节）：钟+山/钟+书、王+震/王+阳、孙+立/孙+思 类——命中即标注"重名风险：高"，强制替换至少一字。
2. **案例拉开**：候选名与 `case-library.md` 经典例证同构时（钟南山式、王震岳式），提示"与案例同构，建议换景换字"，不直接复用案例字面。
3. **组内去重**：同一批候选中，用字重复度检查（同一字最多 2 个候选）。
4. **重名风险评估**：每个候选名输出"独一性"栏——锚点（差异化因子）+ 重名风险（低/中/高 + 一句话原因）。

**撞车替换表（撞车预警/案例拉开的执行依据）**：候选名命中型格高频组合表或与案例同构时，从对应意象行选替换字（结合音韵/型格），并在"独一性"栏注明替换原因（如"与型格高频组合'钟山'撞车，替换为 Y"）：

| 意象 | 高危字（示例） | 替换字 |
|---|---|---|
| 霜/秋 | 霜 序 秋 | 露 霰 霭 素 商 澄 梧 枫 |
| 玉 | 瑾 琼 瑜 | 珩 琬 琰 瑶 琳 珂 璇 瑗 |
| 林/木 | 林 梧 | 桐 楠 杉 樾 柯 棹 栾 |
| 水/澜 | 澜 波 汀 | 漪 涟 沚 滢 浚 淙 泷 |
| 山/岳 | 山 岳 峰 | 峦 岫 岑 崧 峻 嶂 |
| 月/星 | 月 皎 望 | 朔 轮 珺 曜 曦 昶 |
| 云/霞 | 云 霞 岚 | 霭 霓 雯 霏 霁 晞 |
| 端正德字 | 立 守 正 承 | 思 慎 修 笃 恒 敬 谦 允 |

**替换优先序**：同意象替换（保持锚点）＞换第二锚点（换意象）＞换结构（保持锚点换路径）。

## 六、客观边界：独一性是概率优化

- 汉字常用字几千，但"好听+有意义+型格对路"的区间有限，**全国唯一不可承诺**；重名率是概率优化，目标是"不过分"而非"绝无重复"。
- 历史名人名字本身也大量重名（王维不止一人）——名字的价值在于**对这个人成立**，不在全球唯一。
- 撞车预警是"提示与替代"，不是"判死刑"：用户明确偏好某字时，保留并标注风险即可。

## 七、组名设计（双胞胎/兄弟姐妹）

多子女命名是独一性的高级形态：既要有"一听是姐妹/兄弟"的呼应，又不能牺牲各自独立。

**核心方法：同源不同字**——两名共用一个意象源（锚点），拆成两个独立字：
- 秋山 → 岳（山）+ 枫（秋）：岳川 / 枫晚（各自独立成景）
- 雪夜 → 寒松 + 岁柏（冬景各自成立）
- 典源拆句 → 怀瑾 + 握瑜（楚辞同句，各自独立）

**硬规则**：
1. **用字零重复**：两名之间不共用任何字（含虚词缓冲字）——除非用户明确要传统"同辈分字"（清X+清Y式），此时说明会牺牲独一性，由用户选择。
2. **结构不可完全相同**：岳川=偏正、枫晚=偏正反例 / 望岳=动宾、高山=偏正——两名至少一个结构维度不同；完全同构（若X/若Y式，共用同一虚词）降级。
3. **各自独立成立**：去掉另一个，名字依然成立（不做"只有合在一起才完整"的名）。

**呼应层级（按优先级）**：意象同源 ＞ 结构互文 ＞ 同韵收尾。呼应要有，但不以牺牲独立为代价。
